Some of the visual editing tools are created using IPyWidgets, these are available as a Jupyter lab extension. An extension exists to make these widgets accessible in VS Code, and maybe elsewhere. Using Jupyter to view them is preferred. 

Examples 1, 2, and 3 show indended code patterns supported by mg5qs. The first three examples are designed to demonstrate the core functionality of mg5qs, but do not use all avilable utilties or their respective options. More functionality is covered in future examples, but very niche items may not appear. For a complete list of functionality, (before writeing techinacial documenation is completed) write to me or read the source code. Most of the user-facing functionality is found in *mg5qs/python/mg5qs_utils.py*.

**A note to new users:** or any who are unfamilular with this kind of notebook enviernment. A few most important points: a notebook uses a *python interpriter*, so code is not compiled before running; the state of the notebook depends on the order in which the cells are run, running examples out of order is not intended; these envirnments are very well documented on the internet, so any confusing points can easially be clarified there. Ok, last thing, notebook cells can be run with *SHIFT+ENTER*, I find this much eaysier then pushing the run button at the top of the page.
